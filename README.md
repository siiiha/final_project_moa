# 모아 (Moa)

> 가까운 이웃을 연결하고, 계모임과 소모임을 투명하게 운영할 수 있도록 돕는 지역 기반 커뮤니티 서비스

## 프로젝트 소개

모아(MOA)는 지역과 관심사를 바탕으로 이웃들이 계모임과 소모임을 만들고 운영할 수 있는 커뮤니티 플랫폼입니다.
모임 탐색부터 가입, 구성원 간 소통, 일정 공유, 공동자금 관리까지 한곳에서 지원해 일상 속 만남을 더 쉽고 안전하게 시작하도록 돕습니다.

사용자는 활동 지역을 읍·면·동 단위로 설정해 주변 모임을 찾거나 직접 개설할 수 있습니다.
특히 계모임에서는 회비 납부 현황, 수령 순번, 공동자금의 수입·지출 내역과 자금 현황을 투명하게 확인할 수 있습니다.
또, 실시간 채팅·공지·캘린더를 통해 모임 운영 정보를 공유할 수 있어, 운영 과정의 번거로움과 신뢰 문제를 줄입니다.

### 기획 배경

지역 기반 모임은 새로운 관계를 만들고 공동의 활동을 이어가는 좋은 방식이지만, 참여할 사람을 찾기 어렵고 모임 일정·회비·공동자금 관리를 여러 채널에서 처리해야 하는 불편이 있습니다.
또한 회비와 지출 내역이 명확히 공유되지 않으면 구성원 간 신뢰를 유지하기 어렵습니다.

모아는 가까운 이웃과의 연결, 모임 내 소통, 공동자금의 투명한 관리를 하나의 서비스로 제공해 지역 커뮤니티 활동이 자연스럽고 지속되도록 돕는 것을 목표로 합니다.
초기에는 50~60세대의 지역 교류에 주목했으며, 최종적으로는 전 세대가 쉽게 사용할 수 있도록 이용 대상을 확장했습니다.

## 협업 방식

### 브랜치 전략

Git Flow 방식을 참고해 다음과 같이 작업했습니다.

```text
main
└── develop
    ├── feature/{도메인}
    │   └── feature/{도메인}-{세부기능}
    ├── fix/{기능}
    └── docs/{문서}
```

- feature/{도메인} 브랜치를 담당 기능 영역의 통합·정리 브랜치로 활용
- feature/{도메인}-{세부기능} 브랜치에서 세부 기능별 개발 진행
- 세부 기능 개발 완료 후 담당자 통합 브랜치 병합 및 기능 점검
- 통합 브랜치의 테스트와 정리 완료 후 develop 브랜치 Pull Request 등록
- 팀원 리뷰와 피드백 반영 후 develop 브랜치 병합
- main 브랜치의 최종 통합 및 배포 관리
- develop 변경 사항을 주기적으로 반영해 충돌을 예방하고, 충돌 발생 시 코드와 이력을 함께 검토
- Notion, GitHub, ERD Cloud를 활용해 요구사항·API·DB 변경 사항과 회의 내용을 관리
- 매일 진행 상황과 이슈를 공유하고, 코드 리뷰를 통해 기능 통합과 품질을 점검

자세한 Git 사용 방법은 [./GIT_USAGE.md](https://github.com/siiiha/final_project_moa/blob/main/GIT_USAGE.md)에서 확인할 수 있습니다.
